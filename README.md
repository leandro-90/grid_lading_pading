# 📐 Grid Landing Page Project

> ⚠️ **Status do Projeto:** 🚧 **Em andamento** 🚧

Uma landing page moderna criada para demonstrar o uso prático e avançado de layouts baseados em **CSS Grid**, focando em estrutura, alinhamento responsivo e boas práticas de desenvolvimento front-end utilizando exclusivamente HTML e CSS puro.

🔗 **Acesse a prévia do site:** [leandro-90.github.io/grid_lading_pading](https://leandro-90.github.io/grid_lading_pading/)

---

## 📌 Sobre o Projeto

O objetivo principal desta aplicação é explorar e aplicar conceitos de **CSS Grid Layout** em uma estrutura real de landing page. O projeto foca no estudo de posicionamento bidimensional (linhas e colunas), responsividade sem dependência de JavaScript ou *frameworks* externos, e organização semântica do HTML.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** 
  - **CSS Grid Layout:** Alinhamento e estruturação principal da página.
  - **Flexbox:** Componentes internos e alinhamentos unidimensionais.
  - **Media Queries:** Adaptabilidade para múltiplos tamanhos de tela.
  - **Variáveis CSS:** Gerenciamento de cores, fontes e espaçamentos.

> 💡 **Nota:** Este projeto é desenvolvido utilizando 100% **CSS puro** e não utiliza **JavaScript**.
